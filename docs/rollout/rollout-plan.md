# Plano de Rollout

## Fases

| Fase | Duração | Entregáveis |
|---|---:|---|
| Discovery | 1-2 semanas | Requisitos, baseline, riscos. |
| Fundação | 1-2 semanas | Projeto JSM, espaço Confluence, repo. |
| MVP funcional | 2-3 semanas | Request types, workflow, SLAs, queues. |
| KB fase 1 | 2 semanas | Templates, migração e validação inicial. |
| Integração técnica | 2-3 semanas | Integration API e contexto BC. |
| UAT | 1-2 semanas | Testes com agentes e utilizadores internos. |
| Produção controlada | 1 semana | Go-live limitado. |
| Estabilização | 2 semanas | Correções e medição. |

## Critérios de go-live

- Portal criado.
- Request types MVP ativos.
- SLA 24h configurado.
- KB inicial publicada.
- Agentes formados.
- Fluxo de ticket testado.
- Sem secrets no repositório.
- Processo de encaminhamento para agente testado.
- Regra IA KB-only validada.

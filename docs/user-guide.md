# Guia de utilização

## 1. Dashboard

Mostra indicadores locais:

- total de pedidos;
- pedidos em aberto;
- artigos KB;
- pedidos sem sugestão KB;
- pedidos por prioridade.

## 2. Novo pedido

Preencher:

- empresa;
- ambiente;
- tipo de pedido;
- impacto;
- urgência;
- resumo;
- descrição.

Ao clicar em **Analisar com base na KB**, a aplicação procura artigos relevantes.

Se encontrar artigos, apresenta sugestões.  
Se não encontrar, recomenda encaminhamento para agente.

## 3. Pedidos

Permite consultar os pedidos criados neste browser.

Pode alterar o estado:

- Novo;
- Triagem;
- A aguardar informação;
- Em análise;
- Em execução;
- Em validação;
- Resolvido;
- Fechado.

## 4. Base de conhecimento

Permite:

- pesquisar artigos;
- criar artigos;
- editar artigos;
- apagar artigos;
- exportar artigo em Markdown.

## 5. Importar / Exportar

### Exportar JSON

Gera um ficheiro com:

- artigos KB;
- pedidos;
- definições.

### Importar JSON

Substitui os dados locais pelos dados do ficheiro importado.

Usar esta opção com cuidado.

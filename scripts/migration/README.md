# Migration scripts

Scripts de apoio à migração da KB existente para Confluence.

Ordem recomendada:

1. exportar conteúdo fonte;
2. converter para Markdown/JSON intermédio;
3. normalizar metadados;
4. validar secções obrigatórias;
5. detetar duplicados;
6. criar drafts no Confluence;
7. rever e publicar.
